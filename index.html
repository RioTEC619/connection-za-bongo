Mwongozo wa Ku-update InfinityFree & Render (Step-by-Step Hosting)

1. InfinityFree Account Hosting Instructions

  1. Ingia kwenye **InfinityFree Control Panel (cPanel)** au Dashboard yako.
  2. Fungua **Online File Manager** na uende kwenye folda la htdocs/.
  3. Futa au badilisha file la zamani la index.html au index.php.
  4. Upload kodi hizi zote mpya kama index.html.
  5. Kama unatumia backend ya PHP, tengeneza file la config.php kuhifadhi API Key: hpk_88c5a66dc476b8a2e....
  6. Hakikisha SSL Certificate (HTTPS) ipo active kwenye domain yako ya InfinityFree.

2. Render Deployment Instructions

  1. Tengeneza **GitHub Repository** mpya na uweke ma-file yako ya mradi.
  2. Ingia kwenye **Render.com** -> bonyeza **New +** -> chagua **Static Site** au **Web Service**.
  3. Connect na GitHub repo yako.
  4. Weka Environment Variable ya API Key kwenye Render Dashboard:
    PAYMENT_API_KEY = hpk_88c5a66dc476b8a2e1e07555f0830cd674840e79a141e28e
  5. Bonyeza **Deploy Web Service**. Mradi wako utakuwa LIVE mtandaoni bure!
